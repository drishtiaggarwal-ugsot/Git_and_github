## 📌 How to Use This Template

Use **your name** in lowercase with hyphens (e.g., `priya-sharma`) for both your branch and your file. Full steps are in the main `README.md`.

1. Make sure you've forked and cloned the repo.
2. Create a branch with your name:
   ```bash
   git switch -c <your-name>
   ```
3. Copy this template into a new file with your name:
   ```bash
   cp students/_TEMPLATE.md students/<your-name>.md
   ```
   Example: `students/priya-sharma.md`
4. Open **your** file, delete this "How to Use" section, and fill in everything below.
5. Stage, commit, and push:
   ```bash
   git add students/<your-name>.md
   git commit -m "Add introduction for <your-name>"
   git push -u origin <your-name>
   ```
6. Open a Pull Request on GitHub. 🎉

> 💡 **Why a separate file for each student?** If everyone edited the same file, almost every Pull Request would cause a merge conflict. One file per person keeps things clean.

> 🔐 **Privacy reminder:** This repo may be public. Only share what you're comfortable with the whole internet seeing. **Don't** include your phone number, home address, personal email, or date of birth. Every field below is optional.
